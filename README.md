## 📌 Overview

RoutineForge AI is a **phone-first AI productivity platform** designed to reduce the time people spend performing repetitive digital workflows.

Instead of forcing users to manually configure complicated automations, RoutineForge takes a different approach:

> **Show the system how you work once, let AI understand the workflow, review the generated routine, and reuse it safely.**

A user can demonstrate a repetitive workflow such as:

Select document
      ↓
Rename document
